# Benchmark v5: калькулятор оценки (0.8.0) против 0.7.2

## Вопрос

Помогает ли калькулятор статистики оценки `scripts/eval_calc.py` (ветка
`feature/v0.8.0`) давать более точные числа и выводы, чем skill 0.7.2 без
калькулятора.

## Метод

- Шесть расчётных сценариев оценки агента (401–406, `evals/benchmark-calc-v1.json`):
  Pass@k против Pass^k, интервал доли у края шкалы, размер выборки, парное
  сравнение двух версий по фикстуре, граница шума, составное решение.
- 16 эталонов посчитаны независимо от калькулятора (`evals/calc-goldens-v1.json`),
  один главный эталон на сценарий. Запросы фиксируют все соглашения, от которых
  зависит эталон; допуск 1 %, для целых — точное совпадение, для точных p — 0,1 %.
- Один прогон на конфигурацию, 12 ответов, модель opus. Обе конфигурации получали
  одинаковый запрос и одинаковые инструменты, включая Python; отличался только
  путь к skill (снимок 0.8.0 на `713266b`, снимок 0.7.2 на `7536446`).
- Оценка по критериям без указания конфигурации: раскладка A/B по
  `sha256(id) % 2` (`mapping.json`). Слепота формальная: ответ 0.8.0 узнаётся
  по командам калькулятора.
- Точность чисел извлечена из ответов отдельно и сверена с эталонами
  (`calc-accuracy.json`).

## Результат

| Метрика | 0.8.0 | 0.7.2 |
|---|---|---|
| Числа в допуске, все эталоны | 16/16 | 16/16 |
| Числа в допуске, главные эталоны | 6/6 | 6/6 |
| Без эталона обратной команды 401 | 15/15 | 15/15 |
| Критерии оценщика | 16/18 | 18/18 |
| Победы по существу | 0 | 3 (3 ничьи) |

Расхождения по критериям 0 : 2, точный McNemar p = 0,5 — разница не значима.
Оба пропуска 0.8.0 — третьи ожидания 401 и 405, то есть рассуждения по
сценарию, которые калькулятор не печатает; числа в этих ответах верны.

## Вывод

На этих шести сценариях калькулятор не дал выигрыша: opus без него считает те же
величины в Python с той же точностью. Направление по рассуждениям не в пользу
0.8.0, но при N = 6 это не отличимо от шума. Гипотеза, не проверенная: правило
«числа считает скрипт» смещает ответ к выводу инструмента в ущерб выводам по
сценарию. Калькулятор не выпущен; выпущена 0.7.3 с двумя исправлениями
документов, найденными в ходе этой работы.

## Ограничения

- Шесть сценариев и один прогон на конфигурацию: оценка шума невозможна,
  незначимые различия не интерпретируются.
- Отвечала и оценивала одна семья моделей.
- Команда `required-p` добавлена после того, как был написан сценарий 401;
  поэтому точность приведена и без эталона 401 для обратной задачи.
- Ловушка сценария 405 (полоса min–max из вывода `noise` при соглашении ± 2s)
  может стоить баллов только ответу 0.8.0; это раскрыто в поле `note` сценария.
- Сценарии, в которых расчёт труднее (много шагов, большие n, редкие события),
  могли бы показать другую картину; такие сценарии здесь не проверялись.
