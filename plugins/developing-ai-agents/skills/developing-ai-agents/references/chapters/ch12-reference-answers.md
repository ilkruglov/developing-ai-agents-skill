# Справочные ответы на вопросы для размышления: указатель

## Как пользоваться

Книга завершает каждую главу вопросами для размышления, а во второй редакции даёт к ним тезисы ответов в `references/source-book/reference-answers.md`. Многие вопросы совпадают с реальными проектными спорами: «повторно использовать датасет для обучения?», «удовлетворённость как единственная метрика?», «кто утверждает обновления самоэволюционирующего агента?».

Правила применения:

- Тезис ответа — стартовая гипотеза с обоснованием из книги, а не факт о текущем проекте. Проверяй его по коду, трассам и метрикам.
- Если запрос пользователя совпадает с вопросом из таблицы, возьми тезис, привяжи его к наблюдаемому failure mode и укажи якорь `references/source-book/reference-answers.md:LINE` в источниках.
- Для полной аргументации читай сам ответ: здесь только суть в одну строку и куда идти за механизмом.

Якоря ниже указывают на заголовок главы в файле ответов; номер вопроса — на позицию внутри раздела.
