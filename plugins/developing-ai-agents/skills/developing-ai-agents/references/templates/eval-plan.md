# Шаблон: план оценки

## Оглавление

- Назначение
- Обязательные поля
- Форма
- Заполненный пример

## Назначение

Заполняется по `references/playbooks/build-evals.md` до начала оптимизации. Документ должен позволить другому человеку воспроизвести прогон и получить сопоставимые числа.

## Обязательные поля

| Поле | Считается заполненным, если |
|---|---|
| Версии | перечислены все пять: модель, промпт, инструменты, данные, окружение |
| Наборы | указан источник задач, а не только их число |
| Проверка | назван способ, не зависящий от заявления агента |
| Метрики | названа решающая метрика для релиза |
| Повторы | число назначено до первого сравнения |
| Граница шума | измерена, а не оценена на глаз |
| Релизный гейт | пороги заданы числами |
| Откат | назван сигнал и проверено, что откат работает |

## Заполненный пример

```markdown
# План оценки: агент обработки заявок, версия 4

## Зафиксированные версии
| Что | Значение |
|---|---|
| Модель | claude-sonnet-5, temperature 0.2 |
| Промпт | prompts/agent.md @ 4c19f0a |
| Инструменты | tools/ @ 4c19f0a, 7 инструментов |
| Данные | eval/tasks-2026-07.jsonl, срез за июль |
| Окружение | песочница payments-sandbox v3, зафиксированные ответы шлюза |

## Наборы задач
| Набор | Источник | Размер | Когда используется |
|---|---|---|---|
| Разработка | случайная выборка обращений за июль | 120 | каждая итерация |
| Holdout | та же выборка, отложена, доступ закрыт | 60 | только при решении о релизе |
| Adversarial | инциденты из трекера + инъекции + граничные суммы | 35 | каждая итерация |

## Способ проверки результата
| Тип задачи | Проверка |
|---|---|
| Возврат проведён | состояние транзакции в песочнице |
| Отказ с причиной | код причины из справочника, сверка с решением оператора |
| Уведомление отправлено | запись в журнале отправки |
| Соблюдение ограничений | отсутствие вызовов вне окна и лимита |

## Метрики
| Метрика | Как считается | Решающая для релиза |
|---|---|---|
| Доля успешных задач | успех по проверке выше / все задачи | нет |
| Pass^3 | все три прогона задачи успешны | да |
| Нарушения ограничений | число вызовов вне политики | да, порог 0 |
| Доля передач оператору | передачи / все задачи | нет, наблюдаем |
| Стоимость обращения | токены × тариф | нет, бюджет 0.20 USD |
| Задержка p95 | по трассам | нет, бюджет 40 с |

## Статистика
Число повторов: 3 прогона каждой задачи.
Измеренная граница шума: ±3.1 процентного пункта по Pass^3 (пять прогонов
неизменной конфигурации, разброс 78.4–84.6%).
Правило принятия: разница меньше 3.1 пункта решением не считается.
Поправка на множественные сравнения: при сравнении более двух вариантов
победитель подтверждается отдельным прогоном на holdout.

## Релизный гейт
| Условие | Порог |
|---|---|
| Pass^3 на holdout | не ниже текущей версии минус граница шума |
| Нарушения ограничений | 0 на adversarial |
| Регрессии на adversarial | нет новых провалов |
| Стоимость обращения | не выше 0.20 USD |

## Выпуск и откат
Схема выпуска: 5% трафика 24 часа, затем 25% ещё 24 часа.
Сигнал отката: доля передач оператору выше 15% за час либо любое нарушение
ограничения в продакшене.
Проверка отката: выполнен на стенде 2026-08-04, время возврата 4 минуты.
```
